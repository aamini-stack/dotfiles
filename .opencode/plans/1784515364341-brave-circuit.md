# Plan: TDD implementation of `aamini.jj` herdr plugin

Implements `.opencode/plans/1784513157709-mighty-orchid.md` (jj workspace support as a
herdr plugin) test-first. Supersedes that plan's test claims: the existing suite is
**unittest**, not pytest — new tests introduce pytest alongside it.

## Decisions (confirmed with user)

1. New tests in **pytest**; existing unittest files untouched, both suites run.
2. Highest automated layer: **fake `herdr` binary on PATH + real jj** in tmp dirs,
   invoking the real plugin entrypoint as a subprocess.
3. **Reporter daemon is TDD'd** with injected seams (socket connector, clock, spawner).

## Seams (mock only at system boundaries)

| Boundary | Seam | How tested |
|---|---|---|
| herdr CLI | existing `herdr()` in `cli/herdr.py` | `patch.object(module, "herdr")` (unit); fake binary (e2e) |
| jj CLI | NEW `cli/jj.py`: `jj()`, `repo_root()`, `workspace_names()`, `add_workspace()`, `forget_workspace()`, `status_token()` | patch helpers (unit); real jj (e2e) |
| fzf | NEW `cli/plugin/fzf.py`: `fzf_select(lines, preview, binds) -> (key, line)` | patched (unit); fake fzf binary (e2e) |
| TTY input | `input()` | `monkeypatch` builtins / stdin pipe (e2e) |
| plugin state dir | NEW `cli/plugin/state.py`: `state_dir()`, `read/write_context()`, `lock_path()` | `HERDR_PLUGIN_STATE_DIR` → tmp_path |
| socket / time / spawn | reporter injectables: `SocketConnector`, `Clock`, `Sleeper`, `Spawner`, `pid_alive` | fakes in unit tests; tiny fake unix-socket server in e2e |

Reporter keeps logic in a **pure** `compute_reports(workspaces, cache) -> list[Report]`
(token diff, per-workspace `--seq` monotonicity, `--ttl-ms 90000`); `run_loop` is a thin
tested shell with injected `herdr_fn`/`token_fn`.

`jj.workspace_names()` tries `jj workspace list -T 'name ++ "\n"'`, falls back to parsing
default output — the plan's jj-0.43 template risk becomes a tested branch.

## Test layers

### Unit (pytest, `tools/python/cli/tests/`, conftest.py fixtures: `state_env`, `fake_herdr`, `fake_jj`, `fake_clock`)

- **test_jj.py**: stdout return; nonzero→JjError; template vs fallback listing;
  `status_token` → `kxyzqptm ●` (dirty) / `kxyzqptm ✓` (empty); add passes dest+name.
- **test_plugin_wizard.py**: creates `<repo>-<name>` sibling, calls `add_workspace` then
  `open_workspace(dest)`; context from `HERDR_PLUGIN_CONTEXT_JSON`; **fallback to
  state-dir context JSON**; aborts when not in jj repo / empty name / jj add fails;
  arms reporter (cold-start `ensure`).
- **test_plugin_remove.py**: refuses on primary workspace; order close → forget → rm;
  safety check rejects unexpected dir; decline confirm aborts; tolerant when herdr
  workspace missing; fails outside jj repo.
- **test_plugin_picker.py**: focuses existing herdr ws (via `herdr_label_for`); opens new
  when no match; line format `<name>\t<change>\t<dirty>\t<label>`; ctrl-d → remove;
  ctrl-n → wizard; cancel exits cleanly; template-fallback listing.
- **test_plugin_reporter.py**:
  - ensure: spawns when no lockfile; exits when lock alive + same socket; replaces stale
    lock (dead pid); replaces lock for different socket; lockfile name = sha1(socket).
  - compute_reports (pure): reports only on token change; seq monotonic per workspace;
    ttl 90000; token format.
  - loop: exits when socket connect fails repeatedly (server gone); exits after >30s of
    `workspace list` errors; subscribed event refreshes that workspace; polls focused
    every 5s, others every 30s; skips non-jj cwds; `refresh_once` reports all jj ws.

### E2E (`tools/python/cli/tests/e2e/`, marker `e2e`, real jj + fake binaries)

Fixtures: `fake_herdr_bin` (python stub on PATH; appends argv JSON-lines to
`$HERDR_FAKE_LOG`; serves canned responses from `$HERDR_FAKE_SCENARIO`),
`fake_fzf_bin` (selects scripted line), `jj_repo` (real `jj git init` in tmp_path,
skipif no jj), fake unix-socket server. Tests invoke the plugin via
`[sys.executable, "-m", "cli.plugin.main", ...]` (hermetic; not dependent on
`uv tool install` state).

1. `e2e_create_flow` — wizard stdin `feat\n` → real `jj workspace list` contains `feat`;
   sibling dir exists; herdr log has `workspace create --cwd … --label ws-<repo>-feat`,
   `pane split`, `pane run … opencode`.
2. `e2e_remove_flow` — confirm `y` → final real state: `jj workspace list` lacks `feat`,
   dir gone, guard roots pruned; herdr `workspace close` logged.
3. `e2e_remove_refuses_primary` — nonzero exit; workspace + dir intact; no `close` logged.
4. `e2e_picker_focus_existing` — log has `workspace focus <id>`, no `workspace create`.
5. `e2e_picker_opens_new` — log has `workspace create` with real feat dir cwd.
6. `e2e_reporter_ensure_idempotent` — two runs → one lockfile, pid unchanged, exit 0.
7. `e2e_reporter_reports_on_change` — reporter subprocess + fake socket (emits
   `workspace.focused`) + real repo; edit file flips `✓`→`●`; log shows two
   `report-metadata` calls, tokens `✓` then `●`, increasing `--seq`, `--ttl-ms 90000`;
   kill → clean exit on socket close.
