# Plan: `wt` — jj workspace lifecycle CLI

Visual plan + CLI reference: `.lavish/wt-plan.html` (lavish session). This file is the terse source of truth.

## Goal

`wt` owns jj workspace lifecycle (create · hooks · copy-ignored · remove). herdr-jj plugin, jjui, and shell delegate to it. wt is herdr-free. Worktrunk retired; its config API ported.

## Locked decisions

1. wt owns lifecycle; `wizard.py`/`remove.py` delegate, keep herdr UI (focus, labels, reporter)
2. Project config: `<repo>/.config/wt.toml` (worktrunk's path)
3. Commands: `new · rm · ls · hook <name> · copy-ignored` — no gc
4. copy-ignored: gitignored files from primary → new; excludes in `[copy-ignored] exclude` + built-in VCS dirs
5. Env gen: standalone `.local/bin/wt-generate-env`, called by project hooks
6. herdr work = typed-helpers refactor in plugin only (`list_workspaces · find_for_jj · focus_or_create · close_for_jj`), no new UX
7. Hooks: `[[post-create]]` + `[pre-remove]`, named, sequential, blocking. post-create fail → abort create (workspace left). pre-remove fail → warn, continue
8. CLI named `wt`; worktrunk deleted
9. Templates: `{{ name }}` (replaces `{{ branch }}`), `{{ repo }}`, `{{ workspace_path }}`, `{{ primary_path }}`; filters `sanitize · sanitize_db · hash_port` in Python
10. User config `~/.config/wt/config.toml`: `workspace-path` (default `~/.herdr/workspaces/{{ repo }}/{{ name }}`), global excludes, global hooks (run before project hooks)
11. `wt rm`: refuse primary; always confirm prompt, `--yes` skips; then pre-remove → `jj workspace forget` → rmtree. (jj commits survive forget+rmtree — prompt covers untracked-file risk)
12. `wt new <name>` bases on `@`; `-r <revset>` overrides
13. Migration: everything at once

Keep `primary_root()`'s `.jj/repo` pointer detection (jj<0.38 `workspace root --name` gap).
