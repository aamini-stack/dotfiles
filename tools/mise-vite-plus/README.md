# mise-vite-plus

Vendored from `markmals/mise-vite-plus` at commit
`f1744f9a06b0fcfce58d1425e76a202670f590c2`.

This variant reads the configured npm registry and verifies binary tarballs
with the registry-provided SHA-1 digest. It uses npm for the JavaScript
bootstrap because Vite+ does not support the Microsoft CFS metadata routes.
